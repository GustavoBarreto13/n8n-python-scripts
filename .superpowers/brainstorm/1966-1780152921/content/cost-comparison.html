Impacto de custo: Lucy atual vs. ADK

Números reais com Gemini 2.0 Flash — $0.10/1M input, $0.40/1M output

Por que ADK custa mais: o contexto cresce a cada tool call

CADA TURNO DO AGENTE — o contexto acumula:
turno 1
system ~1k tokens
→ fetch_emails()
turno 2
system ~1k
+ 50 emails ~15k tokens
→ label(email_1)
turno 3
system ~1k
+ emails ~15k
+ hist
→ label(email_2)
turno 50+
system ~1k
+ emails ~15k
+ histórico ~10k
💸
Cada turno re-envia o contexto inteiro. 50 emails × contexto crescente = custo explode.

Quando o custo do ADK vale a pena?

✅ ADK faz sentido
  • Tarefa interativa com poucas chamadas
  • Você quer raciocínio multi-step genuíno
  • Comportamento imprevisível é aceitável
  • Volume baixo de operações por execução
⚠️ Script direto é melhor
  • Batch com N itens idênticos (50 emails)
  • Fluxo 100% determinístico e previsível
  • Custo é uma restrição real
  • Output estruturado bem definido
