A virada de chave: Script vs. Agente

O que muda quando você usa o Google ADK

📜 Como funciona hoje (script)
Você (o dev) é o orquestrador.
1. Você decide quais dados coletar
→ busca emails / lê texto
2. Você chama o Gemini 1 vez
→ "analisa tudo e me dê um JSON"
3. Você interpreta a resposta
→ parse, validação, expansão
4. Você chama as APIs externas
→ Notion, IMAP, etc.
O Gemini é uma caixa de extração de dados.
O Python faz toda a lógica.
🤖 Como funciona com ADK (agente)
O Gemini é o orquestrador.
Você define tools (funções Python)
→ create_transaction(), apply_label()...
O agente recebe a instrução
→ "Gastei 89 no Rappi"
↺ O agente entra em loop:
→ pensa → decide chamar create_transaction
→ recebe resultado → confirma → para
O Gemini decide quais funções chamar e quando parar.
Seu Python são só as tools.

O loop que o ADK gerencia pra você

User input
→
Gemini pensa
→
Chama tool
→
Tool executa
→
Gemini avalia resultado
↺
Esse ciclo repete até o Gemini decidir que está feito. Pode ser 1 tool call ou 10. Você não controla — o modelo decide.
✅ Você ganha com ADK
  • Código mais limpo — tools são funções puras
  • Agente pode re-tentar se tool falhar
  • Fácil adicionar novos comportamentos (nova tool)
  • Multi-agente nativo (Nami + Lucy coordenados)
  • Memória de sessão built-in
⚠️ Trade-offs
  • Menos previsível (agente decide o fluxo)
  • Mais tokens por execução (múltiplas chamadas)
  • Mais difícil de debugar
  • Para casos simples, pode ser overkill
  • Requer refactor do código existente
