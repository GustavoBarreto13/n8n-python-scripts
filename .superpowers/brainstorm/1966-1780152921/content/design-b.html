O que muda no n8n

ANTES — Workflow Nami (Telegram)
Telegram Trigger
→ Code node (spawnSync nami/main.py)
→ Telegram Send
DEPOIS — Workflow unificado
Telegram Trigger
→ HTTP Request (POST /chat)
→ Telegram Send
O workflow do Lucy batch (Schedule 8h → spawnSync → Telegram) não muda em nada.

Sessão: como o coordinator "lembra" da conversa

Cada chat_id do Telegram → uma sessão ADK separada.
Você manda "lança 89 no Rappi" → coordinator responde "Lançado ✅"
Você manda "na verdade era 79" → coordinator sabe qual transação corrigir.
⚠️ Memória é in-memory: reiniciar o container limpa o histórico. Para persistência real, precisaria de Firestore ou Redis — não necessário agora.
